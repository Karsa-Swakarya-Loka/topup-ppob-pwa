# TopUpPlay — Progressive Web App (PWA) Top Up Game & PPOB Otomatis

**TopUpPlay** adalah platform PWA (*Progressive Web App*) modern, ringan, dan berkecepatan tinggi untuk layanan top up game resmi (*Mobile Legends, Free Fire, Genshin Impact, Valorant, Steam Wallet*) dan produk digital PPOB (*PLN Token, Pulsa Telkomsel*).

Dibangun dengan arsitektur **Next.js 16 + React 19 + Tailwind CSS v4**, terintegrasi langsung dengan API distributor **Digiflazz H2H (*Host-to-Host*)**, kalkulator margin dinamis, serta sistem kemitraan eksklusif **50% : 50% Streamer Profit Sharing**.

---

## 🚀 Fitur Unggulan

- ⚡ **Proses H2H Instan 1 - 3 Detik**: Otomatisasi pengiriman item langsung ke akun game via API Digiflazz.
- 💎 **Kalkulator Harga Real Digiflazz**: Menghitung harga jual dan perbandingan hemat terhadap kompetitor pasar (Codashop).
- 🤝 **Kemitraan Eksklusif Streamer (50:50 Profit Split)**: Pembagian keuntungan bersih otomatis 50% Owner Web : 50% Partner Streamer dengan tautan bio/livestream khusus.
- 📱 **Progressive Web App (PWA)**: Dapat diinstall langsung ke layar HP tanpa unduh APK, dilengkapi Web Push Notification promo.
- 💳 **Metode Pembayaran Lengkap**: QRIS All Payment (0% Fee), Virtual Account Bank (BCA, Mandiri, BRI, BNI), dan E-Wallet (GoPay, DANA, ShopeePay).
- 🔍 **Cek Nickname Otomatis**: Validasi User ID & Zone ID langsung sebelum checkout untuk mencegah salah kirim.
- 🎨 **Karyalo Gaming Design System**: Antarmuka bersih, elegan, bertipografi Inter berstandar tinggi, dan bebas *AI slop*.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js 16 (App Router)](https://nextjs.org/)
- **UI Library**: [React 19](https://react.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **TypeScript**: Strictly typed definitions
- **PWA**: Service Worker caching, Web Push, Web App Manifest

## 📦 Menjalankan Project Secara Lokal

1. **Clone repository:**
   ```bash
   git clone https://github.com/Karsa-Swakarya-Loka/topup-ppob-pwa.git
   cd topup-ppob-pwa
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Jalankan development server:**
   ```bash
   npm run dev
   ```

4. Buka [http://localhost:3000](http://localhost:3000) di browser Anda.
